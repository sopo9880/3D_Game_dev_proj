Edenfall 사격 감각 테스트 빌드
==============================

Edenfall.exe 를 실행하면 시작 화면이 열립니다. 설치는 필요 없습니다.
"사격장"은 사격과 이동 연습, "혼자 시작 / 호스트 / 참가"는 개발용 샌드박스입니다.
친구와 할 때는 한 명이 "호스트", 나머지가 호스트의 주소를 넣고 "참가"를 누릅니다
(포트 24565/UDP, 같은 빌드끼리만 접속됩니다).
서명되지 않은 개발 빌드라 Windows가 경고를 띄울 수 있습니다
("추가 정보" → "실행").

조작
  WASD 이동 / Shift 달리기 / Space 점프 / Ctrl 또는 C 앉기
  달리다가 앉으면 슬라이딩 / 공중에서 턱 쪽으로 밀면 올라타기
  샌드박스: B 저장소 설치 / N 기준 생산 라인 건설 / X 철거
  좌클릭 사격 / 우클릭 조준 / R 재장전 / 1, 2, 3 또는 휠로 무기 교체
  [ ] 마우스 감도 / T 표적 도전 / F5 통계 초기화
  F1 수치 조정 / F11 전체 화면 / H 도움말 / Esc 일시정지
  F2 규칙 전환: 협동(PvE) <-> 전술 아레나(PvP)
     아레나 규칙은 달리기와 슬라이딩이 없고, 멈춰서 쏴야 정확합니다.
     Shift는 조용히 걷기입니다.

봐 주셨으면 하는 것
  1. 쏘는 순간의 반응이 즉각적인가 (소리, 반동, 적중 표시)
  2. 반동을 손으로 제어할 수 있는가, 너무 밋밋하거나 과하지 않은가
  3. 이동과 슬라이딩이 답답하지 않은가
  4. 무기 3종의 성격이 서로 다르게 느껴지는가
  5. 전술 아레나 규칙(F2)이 원하는 대전 느낌에 가까운가

의견을 숫자로 주는 방법
  F1을 눌러 값을 바꿔 보다가 마음에 드는 상태에서
  "JSON 복사 + 파일 저장"을 누르면 현재 값이 클립보드에 복사됩니다.
  그 내용을 그대로 붙여 넣어 전달해 주세요.

모든 그래픽과 소리는 임시입니다.
