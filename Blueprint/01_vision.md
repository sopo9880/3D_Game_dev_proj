# 01. 비전과 핵심 루프

## 한 문장

> 친구들과 함께 하나의 세계를 **가꾸고, 자동화하고, 싸워서 되살리는** 게임.

플레이어가 어떤 활동을 하든 접속을 끊을 때 "내 세계가 조금 더 나아졌다"는 흔적이 남아야 한다.

| 항목 | 결정 |

## 설계 기둥

기능을 넣을지 판단할 때 쓰는 기준이다. 위에 있을수록 우선한다.

1. **모든 것은 연결된다.** 새 기능은 다른 시스템의 재료를 쓰거나 다른 시스템에 재료를 줘야 한다. 혼자 도는 시스템은 넣지 않는다.
2. **강제하지 않는다.** 농사만, 공장만, 전투만 해도 진행이 막히지 않는다. 다만 다른 활동을 하면 더 빨라진다.
3. **결과는 세계에 남는다.** 건물, 공장, 복원된 자연은 영구적이다. 되돌리는 벌칙(침공으로 파괴, 부패, 유지비)은 넣지 않는다.
4. **벌보다 상.** 공해 벌칙 대신 친환경 설비 보너스. 사망 시 손실 대신 부활.
5. **커져도 느려지지 않는다.** 공장 규모와 프레임이 분리되도록 처음부터 구조를 나눈다.

## 핵심 루프

```
        ┌──────────── 정원·농사 ────────────┐
        │  식물, 생체 재료, 식량            │
        ▼                                   │
   공장·제작  ◀──── 광물, 부품 ──── 탐험·전투
   장비, 자재, 정화 캡슐 ────────────▶      │
        │                                   │
        └──────▶ 구역 복원 ◀────────────────┘
                   │
                   ▼
        새 식물 · 새 건축 부지 · 새 구역 개방
```

각 화살표는 슬라이스에서 실제 아이템으로 구현된다([05](05_vertical_slice.md)의 연결 표 참고).

| 연결 | 슬라이스에서의 구현 |
| --- | --- |
| 정원 → 공장 | 빛잎(작물) → 바이오 연료 → 발전기가 공장을 돌린다 |
| 공장 → 전투 | 철 주괴 → 탄약, 정밀 부품 → 무기 개조 |
| 전투 → 공장 | 적이 떨어뜨린 고철·오염 결정이 레시피 재료 |
| 정원 + 전투 → 복원 | 빛잎 + 오염 결정 → 정화 캡슐 |
| 복원 → 정원 | 복원된 구역에서 새 씨앗과 건축 부지 획득 |

### "강제하지 않는다"의 구체적 보장

- **공장 없이 전투 가능**: 기본 소총과 기본 탄약은 작업대에서 손으로 만들 수 있고, 권총은 탄약이 무한이다.
- **전투 없이 진행 가능(슬라이스 이후)**: 오염 결정은 안전 구역 가장자리의 결정 덩어리에서도 느리게 채집할 수 있다. 단 슬라이스의 미니보스는 필수다. 슬라이스는 루프 전체를 한 번 돌려 보는 것이 목적이기 때문이다.
- **농사 없이 공장 가동 가능(슬라이스 이후)**: 태양광·풍력이 추가되면 바이오 연료는 선택지가 된다.

## 하지 않는 것

범위를 지키기 위해 명시적으로 제외한다. 다시 넣으려면 [07](07_decisions.md)에 근거를 적는다.

- 오픈 월드 PvP, 약탈, 기지 침공
- 호스트가 없을 때 돌아가는 월드(전용 서버) — 출시 후 검토
- 절차 생성 지형, 지형 변형(땅파기)
- 공해·소음·유지비 같은 공장 벌칙
- 배고픔·갈증 생존 수치. 음식은 버프만 준다
- 고정 직업/클래스
- 액체 파이프, 열차, 드론 — 출시 후 확장 후보
- 콘솔, 크로스플레이

## 목표 플레이어

- 친구 2~8명과 주말에 Satisfactory류나 Valheim류를 함께 하는 사람들
- 그 무리 안에서 "나는 건물만 지을래"와 "나는 싸우러 갈래"가 동시에 나오는 그룹

한 무리 안의 서로 다른 취향이 같은 세계에 기여하게 만드는 것이 이 게임의 판매 포인트다.
