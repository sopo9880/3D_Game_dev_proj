# 02. 게임 시스템

각 시스템의 **규칙**을 정한다. 구체 수치는 [05](05_vertical_slice.md), 데이터 형식은 [03](03_data_model.md), 구현 구조는 [04](04_architecture.md).

표기: **[S]** 슬라이스에 포함, **[후]** 슬라이스 이후.

---

## 1. 건축

집, 정원, 공장을 하나의 건축 모드로 다룬다.

### 격자

- 월드 격자 한 칸은 **1m × 1m × 1m**. 구조물 좌표는 정수 칸이다.
- 층 높이는 **4칸**. 바닥은 4×4칸, 벽은 4칸 폭 × 4칸 높이.
- 회전은 90도 단위 4방향.
- 설비는 정수 칸 발자국을 갖는다(예: 제련기 2×3).
- **장식류만 자유 배치**: 위치는 실수, 회전은 Y축 자유. 충돌 검사는 하되 격자를 점유하지 않는다.

### 분류

| 탭 | 예 | 배치 | 단계 |
| --- | --- | --- | --- |
| 건물 | 바닥, 벽, 계단, 지붕 | 격자 | [S] |
| 산업 | 채굴기, 제련기, 벨트, 저장소, 발전기 | 격자 | [S] |
| 자연 | 밭, 화분, 울타리 / 나무, 연못 | 격자 / 자유 | [S] 밭·화분만 |
| 인테리어 | 가구, 조명, 색상 | 자유 | [S] 5종 이내 |

### 설치 규칙

1. 미리보기는 클라이언트가 그린다(초록 = 가능, 빨강 = 불가).
2. 설치 요청은 호스트로 간다. 호스트가 **칸 점유, 지지 여부, 재료, 권한**을 다시 검사한다.
3. 재료는 설치자의 인벤토리에서 즉시 차감. 철거하면 **100% 환급**한다(벌보다 상).
4. 지지 규칙은 단순하게: 바닥은 지면이나 다른 구조물에 닿아야 한다. 구조 강도 계산은 없다.
5. 벨트는 시작점과 끝점을 찍으면 직선 구간이 한 번에 깔린다. 높이 변화는 경사 벨트.

### 편의 기능

| 기능 | 규칙 | 단계 |
| --- | --- | --- |
| 되돌리기 | 본인의 최근 설치/철거 20개. 그 사이 다른 변경이 있으면 실패 처리 | [S] |
| 복사(스포이트) | 조준한 구조물과 같은 종류·회전을 손에 듦 | [S] |
| 일괄 철거 | 드래그 영역. 권한 있는 것만 | [후] |
| 청사진 | 영역을 저장해 다시 설치 | [후] |

### 권한

월드 단위 역할 3종. 호스트가 플레이어별로 지정하고 세이브에 저장된다.

| 역할 | 설치 | 철거 | 설비·상자 사용 |
| --- | --- | --- | --- |
| 소유자(호스트) | O | 전부 | O |
| 건설자 | O | 전부 | O |
| 방문자 | X | X | O |

새로 들어온 친구의 기본 역할은 **건설자**다(월드 설정에서 변경 가능). 모든 구조물은 `설치자 ID`를 기록하므로 "내 것만 철거" 같은 세분화는 나중에 데이터 변경 없이 추가할 수 있다.

## 2. 공장

### 원칙

- 벨트 위 물건은 물리 객체가 아니다. 호스트가 숫자로 계산하고 클라이언트가 그린다.
- 시뮬레이션은 **10Hz 고정 틱, 정수 연산**. 같은 입력이면 항상 같은 결과가 나온다.
- 플레이어와의 거리에 따라 계산을 바꾸지 않는다.
- 호스트가 월드를 닫으면 멈춘다. 다시 열 때 밀린 시간을 따라잡지 않는다.

### 설비 종류

| 종류 | 역할 | 포트 | 단계 |
| --- | --- | --- | --- |
| 채굴기 | 광맥 위에 설치, 광석 생산 | 출력 1 | [S] |
| 제련기 | 재료 1종 → 생산물 1종 | 입력 1, 출력 1 | [S] |
| 조립기 | 재료 2종 → 생산물 1종 | 입력 2, 출력 1 | [S] |
| 벨트 | 물건 운반 | 양 끝 | [S] |
| 분배/합류기 | 최대 3방향으로 번갈아 나눔 / 합침 | 입력 ≤3, 출력 ≤3 | [S] |
| 저장소 | 물건 보관 | 입력 1, 출력 1 | [S] |
| 바이오 발전기 | 연료를 태워 전력 생산 | 입력 1 | [S] |
| 자동 수확기, 온실, 태양광, 풍력, 축전지 | | | [후] |

### 연결

- 설비에는 방향이 정해진 **포트**가 있다. 벨트 끝을 포트에 닿게 깔면 연결된다. 집게팔은 없다.
- 플레이어는 어떤 설비든 상호작용해 내부 슬롯에 손으로 넣고 뺄 수 있다. 1단계 "개인 작업장"은 벨트 없이 이것만으로 돌아간다.

### 벨트 모델

- 이어진 직선·곡선 벨트는 하나의 **벨트 라인**으로 합쳐 계산한다.
- 라인은 **칸당 슬롯 1개**의 배열이다. 각 슬롯은 비었거나 아이템 ID 하나를 갖는다.
- 라인은 `이동 주기(틱)`마다 한 번, 앞에서 뒤로 훑으며 앞 칸이 비었으면 한 칸 전진시킨다. 끝 슬롯의 물건은 연결된 포트가 받을 수 있을 때만 넘어간다.
- 속도는 등급별 고정값. 기본 벨트는 이동 주기 5틱 = 초속 2칸 = **분당 120개**.
- 화면에서는 이동 주기 사이를 보간해 매끄럽게 흐르는 것처럼 그린다.

이 모델에서 계산량은 물건 개수가 아니라 슬롯 수에 비례하고, 최적화 여지(움직이지 않는 구간 건너뛰기)가 분명하다.

### 생산 모델

- 기계는 레시피 하나를 선택한다. 입력 버퍼에 재료가 모이면 `제작 시간(틱)` 동안 진행하고 출력 버퍼에 놓는다.
- 출력 버퍼가 가득 차면 멈춘다(역류 압력). 이것이 병목을 눈에 보이게 만든다.
- 기계 상태 5종: `가동 / 재료 부족 / 출력 막힘 / 전력 부족 / 레시피 없음`. 기계 위 아이콘과 상호작용 패널에 표시한다.

### 생산 관리 UI

| 기능 | 단계 |
| --- | --- |
| 기계 패널: 현재 레시피, 상태, 최근 60초 실제 생산량(개/분) | [S] |
| 벨트 조준 시: 최근 60초 통과량 | [S] |
| 전력망 패널: 공급 / 수요 / 충족률 | [S] |
| 공장 전체 통계 화면, 병목 강조 표시 | [후] |

## 3. 전력

- 전선 없이 **범위 기반**: 발전기와 설비가 서로의 전력 범위(반경) 안에 있으면 같은 전력망이다. 전력 중계 기둥으로 범위를 잇는다. [S]는 중계 기둥 1종.
- 매 틱 전력망마다 `충족률 = min(1, 공급 / 수요)`. 기계의 진행 속도에 충족률을 곱한다. 완전 정전은 없고 느려질 뿐이다.
- 가동 중이 아닌 기계는 수요가 0이다.
- 축전지 [후]: 남는 전력을 저장했다 부족할 때 방출.
- 친환경 보너스 [후]: 태양광·풍력은 복원 완료 구역에 놓으면 출력이 오른다.

## 4. 농사와 정원

- **밭**(2×2칸 구조물)에 씨앗을 심는다. 성장은 호스트의 틱으로 계산한다.
- 성장 단계 4개(씨앗 → 새싹 → 성장 → 수확 가능). 물을 주면 다음 단계까지의 시간이 절반이 된다. 물을 안 줘도 죽지 않는다.
- 수확하면 작물과 일정 확률로 씨앗이 나오고 밭은 비워진다.
- 화분은 장식용 식물을 심는 1×1 구조물. 성장만 하고 수확은 없다.
- 계절, 날씨, 시듦, 해충은 없다.
- 자동 관수·자동 수확기 [후]: 밭에 인접 설치하면 수확물이 포트로 나온다. 여기서 농장이 공장에 벨트로 직접 연결된다.
- 동물 교감 [후]: 복원된 구역에 동물이 나타난다. 길들이기·사육은 출시 범위 밖 검토.

## 5. 구역과 복원

월드는 **구역**으로 나뉘고 구역마다 복원 진행도(0~100)를 갖는다.

| 상태 | 진행도 | 모습 |
| --- | --- | --- |
| 오염 | 0 | 탁한 색, 죽은 식생, 적 출현, 불안한 환경음 |
| 회복 중 | 1~99 | 진행도에 따라 색·안개·식생이 서서히 변함. 적 출현 빈도 감소 |
| 복원 완료 | 100 | 꽃과 나무, 동물, 밝은 음악. 적 없음. 건축 가능 |

### 복원 방법

1. 구역의 우두머리(미니보스/보스)를 처치해 **에너지 코어**를 얻는다.
2. 코어와 자재로 구역 중심에 **복원 비콘**을 건설한다.
3. 비콘에 **정화 캡슐**을 넣는다. 캡슐 하나가 진행도를 고정량 올린다. 벨트로도 넣을 수 있다.
4. 100이 되면 복원 완료. 되돌아가지 않는다.

### 복원 보상

- 구역 고유 씨앗과 장식 식물 해금
- 그 구역에서 건축 가능
- 다음 구역으로 가는 길 개방

### 연출

진행도는 구역 단위 셰이더 파라미터 하나로 지면·식생·안개·조명에 전달된다. 식생과 동물은 진행도 문턱(25/50/75/100)에서 단계적으로 등장한다. 모든 클라이언트는 진행도 숫자만 동기화받는다.

## 6. 전투 (FPS)

### 조작

걷기, 달리기, 점프, 앉기, 슬라이딩 [S]. 대시·이단 점프 등 특수 이동은 장비로 해금 [후].

### 무기

- 슬롯 2개 + 권총(항상 소지, 탄약 무한).
- 히트스캔 위주. 느린 투사체는 특수 무기에만.
- 반동은 정해진 패턴 + 소량의 무작위. 조준(ADS) 지원.
- 개조 [S 1종, 이후 확장]: 작업대에서 부품을 써서 무기 수치 하나를 올린다.
- 특수 장비 [후]: 씨앗 발사기(속박·임시 엄폐물), 전자기 무기(기계형 보호막 제거).

### 적

- 호스트가 AI를 돌린다. 길찾기는 NavigationServer3D.
- 오염·회복 중 구역에만 나타난다. 정원(안전 구역)에는 절대 오지 않는다.
- 기지 습격은 없다.
- 협동 보정: 적 체력 × `(1 + 0.5 × (인원 − 1))`.
- 적은 플레이어 구조물을 공격하지 않는다.

### 사망

- 쓰러지면 30초 동안 동료가 부활시킬 수 있다.
- 그 시간이 지나거나 혼자면 가장 가까운 안전 지점(정원 또는 복원된 구역)에서 부활한다.
- **잃는 것은 없다.** 소지품과 장비는 그대로다.

### 전리품

적이 죽으면 전리품은 **플레이어마다 따로** 생긴다(각자 자기 몫을 줍는다). 누가 먼저 줍는지 다툴 일이 없다.

## 7. 협동

| 상황 | 처리 |
| --- | --- |
| 혼자 플레이 | 같은 월드를 인원 1로 연다. 코드 경로는 멀티와 동일 |
| 친구 접속 | 진행 중인 월드에 중도 참가. 전체 스냅샷을 받고 시작 |
| 떨어져서 활동 | 제한 없음 |
| 공장 계산 | 호스트만 계산 |
| 친구 접속 종료 | 그 플레이어의 위치·소지품·진행을 호스트 세이브에 기록 |
| 호스트 종료 | 저장 후 모두 메인 메뉴로 |
| 호스트 연결 끊김 | 클라이언트는 메인 메뉴로. 호스트 이전(migration)은 없다 |

### 공유와 개인

| 공유(월드) | 개인(플레이어) |
| --- | --- |
| 구조물, 공장, 저장소 내용물 | 인벤토리, 장착 무기와 개조 |
| 구역 복원 진행도 | 위치, 체력 |
| 해금된 레시피(연구) | 전리품 |
| 발견한 지도 | 장식·칭호(계정 단위) |

레시피 해금을 월드 공유로 둔 이유: 한 명이 유적에서 설계도를 찾으면 모두가 쓸 수 있어야 역할 분담이 의미가 있다.

## 8. PvP 놀이 광장 [후 — M5]

- 정원에 놓는 **아레나 구조물**에 상호작용해 참가한다. 전원이 준비를 눌러야 시작한다.
- 경기 중인 플레이어만 서로에게 피해를 줄 수 있다. 그 밖의 모든 곳에서 아군 피해는 없다.
- 장비는 경기용 고정 세트로 바뀌고, 끝나면 원래대로 돌아온다. 월드 인벤토리는 건드리지 않는다.
- 보상은 장식과 칭호뿐이다.
- 출시 구성은 **페인트 배틀(1v1, 2v2)** 하나. 씨앗 쟁탈전·서바이벌·장애물 레이스는 같은 "경기" 틀에 얹는 확장이다.
