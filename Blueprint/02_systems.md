# 02. 게임 시스템

각 시스템의 **규칙**을 정한다. 구체 수치는 [05](05_vertical_slice.md), 데이터 형식은 [03](03_data_model.md), 구현 구조는 [04](04_architecture.md).

표기: **[S]** 슬라이스에 포함, **[후]** 슬라이스 이후.

## 1. 건축

집, 정원, 공장을 하나의 건축 모드로 다룬다.

### 격자

- 월드 격자 한 칸은 **1m × 1m × 1m**. 구조물 좌표는 정수 칸이다.
- 층 높이는 **4칸**. 건물 조각은 4칸 격자에 맞는다.
- 회전은 90도 단위 4방향.

조각마다 격자를 쓰는 방식이 다르다.

| 조각 | 차지하는 것 | 비고 |
| --- | --- | --- |
| 설비, 벨트, 계단, 작업대, 밭 | **칸** | 같은 칸에 둘을 놓을 수 없다 |
| 바닥, 지붕 | 칸의 **밑면** (4×4칸, 두께 0.2m) | 칸을 차지하지 않으므로 그 위에 설비를 놓는다 |
| 벽 | 칸의 **모서리** (4칸 폭 × 4칸 높이, 두께 0.2m) | 칸을 막지 않는다. 벽에 붙여 설비를 놓을 수 있다 |
| 장식 | 없음 (자유 위치, 자유 회전) | 위치는 밀리미터 정수로 저장해 모든 피어에서 같다. 다른 장식과 30cm 안에는 놓을 수 없다 |

### 건축 구역

- 건축은 **건축 구역** 안에서만 된다. 구역은 높이가 정해진 평평한 단이고, 그 높이가 그 구역의 지면이다.
- 구역 밖(경사지, 길, 전투 구역)에는 지을 수 없다. 경계는 화면에 표시한다.
- 구역은 월드 상태의 일부다. 구역을 복원하면 그곳의 건축 구역이 열린다(M3).
- 구역이 하나도 정의되지 않은 월드는 전체가 높이 0의 평지다(테스트용).

### 받침

허공에는 지을 수 없다. 규칙은 단순하게 유지한다.

- 그 구역의 지면에는 무엇이든 놓을 수 있다.
- 설비·벨트는 아래에 바닥판이나 다른 구조물이 있어야 한다.
- 바닥은 아래층 벽의 꼭대기에 닿거나, 같은 높이의 바닥과 이웃하거나, 아래에 구조물(계단 꼭대기 등)이 있어야 한다.
- 벽은 바닥 위나 아래층 벽 위에 선다.
- **받침을 철거해도 위의 것은 무너지지 않는다.** 구조 강도 계산은 없다("결과는 세계에 남는다").

### 분류

| 탭 | 예 | 배치 | 단계 |
| --- | --- | --- | --- |
| 건물 | 바닥, 벽, 계단, 지붕 | 격자 | [S] |
| 산업 | 채굴기, 제련기, 벨트, 저장소, 발전기 | 격자 | [S] |
| 자연 | 밭, 화분, 울타리 / 나무, 연못 | 격자 / 자유 | [S] 밭·화분만 |
| 인테리어 | 가구, 조명, 색상 | 자유 | [S] 5종 이내 |

### 설치 규칙

1. 미리보기는 클라이언트가 그린다(초록 = 가능, 빨강 = 불가와 그 이유). 설비의 입력·출력 포트는 화살표로 보인다. 조작과 화면은 [09](09_building_design_plan.md).
2. 설치 요청은 호스트로 간다. 호스트가 **자리, 받침, 재료, 권한**을 다시 검사한다. 거절되면 이유가 화면에 뜬다.
3. 재료는 설치자의 소지품에서 차감한다. 철거하면 설치 비용 전액과 안에 든 것이 **철거한 사람**에게 돌아간다(벌보다 상).
4. 지지 규칙은 단순하게: 바닥은 지면이나 다른 구조물에 닿아야 한다. 구조 강도 계산은 없다.
5. 벨트는 시작점과 끝점을 찍으면 ㄱ자 경로가 한 번에 깔린다. 양 끝이 포트 앞이면 포트에 곧게 이어지는 쪽으로 꺾인다. 비용은 4칸당 주괴 1개.
6. **경사 벨트**: 끝점의 높이가 시작점과 다르면(예: 2층 바닥을 조준) 벨트가 한 칸 갈 때마다 1m씩 오르내린다. 경사 구간은 받침 없이 스스로 버티고, 평평한 구간은 바닥이 있어야 한다. 4m를 오르려면 수평으로 4칸 이상이 필요하다.

### 편의 기능

| 기능 | 규칙 | 단계 |
| --- | --- | --- |
| 되돌리기 (Z) | 본인의 최근 설치/철거 20개. 설치를 되돌리면 철거, 철거를 되돌리면 다시 설치. 그 사이 상황이 바뀌었으면 호스트가 거절한다 | 구현됨 |
| 같은 것 고르기 (F) | 조준한 구조물과 같은 종류·회전을 손에 듦 | 구현됨 |
| 일괄 철거 | 드래그 영역. 권한 있는 것만 | [후] |
| 청사진 | 영역을 저장해 다시 설치 | [후] |

### 권한

월드 단위 역할 3종. 호스트가 플레이어별로 지정하고 세이브에 저장된다.

| 역할 | 설치 | 철거 | 설비·상자 사용 |
| --- | --- | --- | --- |
| 소유자(호스트) | O | 전부 | O |
| 건설자 | O | 전부 | O |
| 방문자 | X | X | O |

새로 들어온 친구의 기본 역할은 **건설자**다(월드 설정에서 변경 가능). 모든 구조물은 `설치자 ID`를 기록하므로 "내 것만 철거" 같은 세분화는 나중에 데이터 변경 없이 추가할 수 있다.

## 2. 공장

### 원칙

- 벨트 위 물건은 물리 객체가 아니다. 호스트가 숫자로 계산하고 클라이언트가 그린다.
- 시뮬레이션은 **10Hz 고정 틱, 정수 연산**. 같은 입력이면 항상 같은 결과가 나온다.
- 플레이어와의 거리에 따라 계산을 바꾸지 않는다.
- 호스트가 월드를 닫으면 멈춘다. 다시 열 때 밀린 시간을 따라잡지 않는다.

### 설비 종류

| 종류 | 역할 | 포트 | 단계 |
| --- | --- | --- | --- |
| 채굴기 | 광맥 위에 설치, 광석 생산 | 출력 1 | [S] |
| 제련기 | 재료 1종 → 생산물 1종 | 입력 1, 출력 1 | [S] |
| 조립기 | 재료 2종 → 생산물 1종 | 입력 2, 출력 1 | [S] |

### 연결

- 설비에는 방향이 정해진 **포트**가 있다. 벨트가 포트에서 **곧게 나오거나 곧게 들어가도록** 깔면 연결된다(옆에서 붙이면 연결되지 않는다). 집게팔은 없다.
- 벨트 옆구리로 합류시키는 것은 지원하지 않는다. 합칠 때는 분배/합류기를 쓴다.
- 플레이어는 어떤 설비든 상호작용해 내부 슬롯에 손으로 넣고 뺄 수 있다. 1단계 "개인 작업장"은 벨트 없이 이것만으로 돌아간다.

### 벨트 모델

- 이어진 직선·곡선 벨트는 하나의 **벨트 라인**으로 합쳐 계산한다.
- 라인은 **칸당 슬롯 1개**의 배열이다. 각 슬롯은 비었거나 아이템 ID 하나를 갖는다.
- 라인은 `이동 주기(틱)`마다 한 번, 앞에서 뒤로 훑으며 앞 칸이 비었으면 한 칸 전진시킨다. 끝 슬롯의 물건은 연결된 포트가 받을 수 있을 때만 넘어간다.
- 속도는 등급별 고정값. 기본 벨트는 이동 주기 5틱 = 초속 2칸 = **분당 120개**.
- 화면에서는 이동 주기 사이를 보간해 매끄럽게 흐르는 것처럼 그린다.

이 모델에서 계산량은 물건 개수가 아니라 슬롯 수에 비례하고, 최적화 여지(움직이지 않는 구간 건너뛰기)가 분명하다.

### 생산 모델

- 기계는 레시피 하나를 선택한다. 입력 버퍼에 재료가 모이면 `제작 시간(틱)` 동안 진행하고 출력 버퍼에 놓는다.
- 출력 버퍼가 가득 차면 멈춘다(역류 압력). 이것이 병목을 눈에 보이게 만든다.
- 기계 상태 5종: `가동 / 재료 부족 / 출력 막힘 / 전력 부족 / 레시피 없음`. 기계 위 아이콘과 상호작용 패널에 표시한다.

## 3. 전력

- 전선 없이 **범위 기반**: 발전기와 설비가 서로의 전력 범위(반경) 안에 있으면 같은 전력망이다. 전력 중계 기둥으로 범위를 잇는다. [S]는 중계 기둥 1종.
- 매 틱 전력망마다 `충족률 = min(1, 공급 / 수요)`. 기계의 진행 속도에 충족률을 곱한다. 완전 정전은 없고 느려질 뿐이다.
- 가동 중이 아닌 기계는 수요가 0이다.
- 축전지: 전력망에 남는 전력을 저장했다가 모자랄 때 내놓는다. 여러 대가 있으면 ID 순서로 채우고 비운다.
- 연료 없는 발전(태양광·풍력)은 수요와 무관하게 늘 출력을 낸다. 낮밤과 바람의 변화는 없다(D-064).
- 친환경 보너스: 태양광·풍력을 복원이 끝난 구역 안에 놓으면 출력이 1.5배다. 벌이 아니라 상으로 자연 복원과 공장을 잇는다.

## 4. 농사와 정원

- **밭**(2×2칸 구조물)에 씨앗을 심는다. 성장은 호스트의 틱으로 계산한다.
- 성장 단계 4개(씨앗 → 새싹 → 성장 → 수확 가능). 물을 주면 다음 단계까지의 시간이 절반이 된다. 물을 안 줘도 죽지 않는다.
- 수확하면 작물과 일정 확률로 씨앗이 나오고 밭은 비워진다.
- 화분은 장식용 식물을 심는 1×1 구조물. 성장만 하고 수확은 없다.
- 계절, 날씨, 시듦, 해충은 없다.
- 관수기와 자동 수확기: 가로세로 4칸 안의 밭을 돌본다. 수확기는 거둔 작물을 출력 포트로 내보내므로, 여기서 농장이 공장에 벨트로 직접 연결된다(밭 → 수확기 → 벨트 → 조립기 → 바이오 연료 → 발전기). 수확기는 거둔 자리에 같은 작물을 다시 심고 씨앗을 쓰지 않는다. 추가 씨앗은 손으로 거둘 때만 나온다.
- 동물 교감 [후]: 복원된 구역에 동물이 나타난다. 길들이기·사육은 출시 범위 밖 검토.

## 5. 구역과 복원

월드는 **구역**으로 나뉘고 구역마다 복원 진행도(0~100)를 갖는다.

| 상태 | 진행도 | 모습 |
| --- | --- | --- |
| 오염 | 0 | 탁한 색, 죽은 식생, 적 출현, 불안한 환경음 |
| 회복 중 | 1~99 | 진행도에 따라 색·안개·식생이 서서히 변함. 적 출현 빈도 감소 |
| 복원 완료 | 100 | 꽃과 나무, 동물, 밝은 음악. 적 없음. 건축 가능 |

### 복원 방법 (구현됨)

1. 구역의 우두머리(미니보스/보스)를 처치해 **에너지 코어**를 얻는다.
2. 코어와 자재로 구역 중심의 **정해진 자리**에 **복원 비콘**을 건설한다. 자리는 구역마다 하나이고 화면에 표시된다.
3. 비콘에 **정화 캡슐**을 넣는다. 캡슐 하나가 진행도를 고정량 올린다. 벨트로도 넣을 수 있다.
4. 100이 되면 복원 완료. 되돌아가지 않는다.

### 복원 보상

- 구역 고유 씨앗과 장식 식물 해금
- 그 구역에서 건축 가능
- 다음 구역으로 가는 길 개방

### 연출

진행도는 구역 단위 셰이더 파라미터 하나로 지면·식생·안개·조명에 전달된다. 식생과 동물은 진행도 문턱(25/50/75/100)에서 단계적으로 등장한다. 모든 클라이언트는 진행도 숫자만 동기화받는다.

## 6. 전투 (FPS)

### 조작과 파쿠르

기본 이동은 걷기, 달리기, 점프, 앉기, 슬라이딩이다. 여기에 **파쿠르**를 더해 지형과 건물을 타고 넘는 것 자체가 재미가 되게 한다.

| 동작 | 설명 | 단계 |
| --- | --- | --- |
| 올라타기 | 공중에서 턱(발 기준 2.1m 이하) 쪽으로 밀면 잡고 올라간다. 낮은 장애물은 뛰어넘기가 된다 | 구현됨 |
| 매달리기(렛지 그랩) | 올라타기에는 높지만 손이 닿는 턱(발 기준 2.7m 이하)을 붙잡고 매달린다. 벽을 바라본 채 떨어지다 스치는 턱도 잡는다. W·점프 = 오르기, A/D = 옆걸음, S·앉기 = 놓기, 벽을 등지고 점프 = 차고 나가기 | 구현됨 |
| 슬라이딩 점프 | 슬라이딩 중 점프하면 속도를 유지한다 | 구현됨 |
| 벽 달리기 | 달리다가 공중에서 옆에 벽이 있으면 최대 1.2초 벽을 타고 달린다. 천천히 가라앉는다 | 구현됨 |
| 벽 차기 | 공중에서 벽 가까이 점프를 누르면 반대쪽으로 튄다. 같은 벽을 연달아 찰 수는 없어서, 마주 보는 두 벽을 번갈아 차며 오른다 | 구현됨 |
| 줄 타기 / 덩굴 갈고리 | 정해진 지점이나 덩굴 갈고리(보조 무기)로 이동 | [후] M5 |

원칙:

- 파쿠르는 **전부 기본 동작**이다. 해금하거나 스태미나를 쓰지 않는다. 갈고리처럼 도구가 필요한 것만 장비다.
- 맵과 건축이 이것을 받쳐야 한다. 구역에는 높낮이와 지름길을 두고, 플레이어가 지은 바닥·벽·지붕도 똑같이 타고 오를 수 있다(공장 지붕 위를 달리는 것이 되어야 한다).
- 파쿠르 중에도 쏠 수 있지만 부정확하다. 올라타는 동안과 매달려 있는 동안에는 총이 내려가 쏠 수 없다.
- 점프(1.2m)와 올라타기(2.1m)를 합치면 3.3m, 매달리기까지 쓰면 3.9m 높이의 턱에 닿는다. 4m 벽은 벽 차기 없이는 넘지 못한다. 맵과 건물 높이는 이 숫자를 기준으로 잡는다.
- 전술 아레나에서는 파쿠르를 끈다(규칙 묶음의 `allow_mantle` 등). 아레나는 위치와 정확도의 게임이다.

### 무기와 장비

**능력(스킬) 버튼은 없다.** 특수한 효과는 전부 손에 드는 **보조 무기**나 던지는 **투척류**로 만든다. 쿨다운 대신 탄약과 개수로 관리하고, 공장에서 만들어 보충한다. 협동과 아레나 모두 같은 원칙이다.

| 칸 | 내용 |
| --- | --- |
| 주무기 2 | 돌격소총, 샷건, 정밀 사격 무기 등 |
| 보조 무기 1 | 권총(기본, 탄약 무한) 또는 특수 보조 무기 |
| 투척 2 | 종류별로 몇 개씩 소지 |

- 히트스캔 위주. 느린 투사체는 보조 무기와 투척류에만.
- **근접 공격(V)**: 든 총으로 후려친다. 피해 45, 0.6초 간격, 탄약이 들지 않는다. 앞쪽 약 2.5m 안의 적 최대 3명이 맞고, 맞은 적은 잠깐 움찔하며 하던 공격이 끊긴다. 탄약이 떨어졌을 때의 대비책이자 달라붙은 돌진형을 떼어 내는 수단이다. 전용 근접 무기는 [후].
- 반동은 정해진 패턴 + 소량의 무작위. 조준(ADS) 지원.
- 개조 [S 1종, 이후 확장]: 작업대에서 부품을 써서 무기 수치 하나를 올린다.

보조 무기와 투척류 후보 [후]. 전부 공장 생산물이 재료다.

| 종류 | 이름 | 효과 |
| --- | --- | --- |
| 보조 무기 | 씨앗 발사기 | 맞은 적을 덩굴로 묶거나, 바닥에 쏘면 임시 엄폐물이 자란다 |
| 보조 무기 | 전자기 권총 | 기계형 적의 보호막을 벗긴다 |
| 보조 무기 | 덩굴 갈고리 | 걸린 지점으로 몸을 당긴다(파쿠르 도구) |
| 투척 | 포자 연막 | 시야를 막는 구름 |
| 투척 | 섬광 꽃가루 | 바라본 대상의 시야를 잠깐 가린다 |
| 투척 | 정화 수류탄 | 오염된 적에게 범위 피해, 오염 지대를 잠깐 걷어 낸다 |
| 투척 | 탐지 씨앗 | 박힌 곳 주변의 적을 잠깐 드러낸다 |

### 적

- 호스트가 AI를 돌린다. 길찾기는 NavigationServer3D.
- 오염·회복 중 구역에만 나타난다. 정원(안전 구역)에는 절대 오지 않는다. 출현 지점에서 45m 안에 플레이어가 있을 때만 나오고, 코앞(12m 안)에는 나오지 않는다.
- 우두머리는 플레이어가 그 터에 들어서면 나타난다. 모두 떠나면 물러나고 체력이 처음으로 돌아간다. 한 번 쓰러뜨리면 다시 나오지 않는다.
- 기지 습격은 없다.
- 난이도(쉬움/보통/어려움)는 월드 설정이다. 적의 체력과 피해에 배율을 곱한다(보통: 1.35배, 1.3배). 호스트가 F7이나 새 월드를 만들 때 고른다.
- 협동 보정: 적 체력 × `(1 + 0.5 × (인원 − 1))`. 기준 인원은 **그 구역에 있는 플레이어 수**다(8명이 접속해도 2명만 싸우러 갔으면 2인 기준). 5인 이상에서는 체력만 올리면 지루해지므로 동시 출현 수도 함께 늘린다(수치는 M4에서 조정).
- 혼자서도 모든 전투 콘텐츠를 끝낼 수 있어야 한다. 보스 패턴에 "2명이 동시에 해야 하는 일"을 넣지 않는다.
- 적은 플레이어 구조물을 공격하지 않는다.

### 사망

- 체력 100. 5초간 피해가 없으면 초당 10 회복.
- 쓰러지면 30초 동안 동료가 일으킬 수 있다(3m 안에서 E를 2초). 일어나면 체력 30.
- 그 시간이 지나면 가장 가까운 안전 지점(정원 또는 복원된 구역)에서 다시 일어난다. 일으켜 줄 사람이 아무도 없으면(혼자이거나 전원이 쓰러짐) 3초만 기다린다.
- **잃는 것은 없다.** 소지품과 장비는 그대로다.

### 전리품

적이 죽으면 전리품은 **플레이어마다 따로** 굴린다. 처치한 사람과 60m 안에 있던 사람 모두 자기 몫을 받으므로 누가 먼저 줍는지 다툴 일이 없다. 지금은 즉시 소지품에 들어가고, 바닥에 떨어져 줍는 방식은 인벤토리(M2)와 함께 넣는다.

## 8. PvP 전술 아레나 [후 — M5]

친구끼리 하는 이벤트 대전. 목표는 **라운드제 전술 슈터의 긴장감**이다: 한 라운드에 목숨 하나, 정확한 첫 발, 위치와 정보 싸움, 짧은 교전. 협동 월드의 빠르고 너그러운 전투와는 일부러 다르게 만든다.

장르의 규칙과 감각을 따르되, 캐릭터·맵·능력·이름은 전부 Edenfall의 것으로 새로 만든다.

### 참가

- 정원에 놓는 **아레나 구조물**에 상호작용해 참가한다. 전원이 준비를 눌러야 시작한다.
- 경기는 월드와 분리된 전용 맵에서 열린다. 참가하지 않은 사람은 월드에서 하던 일을 계속한다.
- 경기 중인 플레이어만 서로에게 피해를 줄 수 있다. 그 밖의 모든 곳에서 아군 피해는 없다.
- 장비와 체력은 경기용으로 바뀌고, 끝나면 원래대로 돌아온다. 월드 인벤토리는 건드리지 않는다.
- 보상은 장식과 칭호뿐이다. 공장을 오래 키운 사람이 유리해지는 요소는 없다.

### 기본 모드: 씨앗 심기 (공격 vs 수비)

| 항목 | 규칙 |
| --- | --- |
| 인원 | 1v1 ~ 4v4. 인원이 다르면(3v4 등) 적은 쪽에 라운드 자금 보정 |
| 승리 | **7라운드 선승**. 6라운드 뒤 공수 교대. 6:6이면 단판 연장 |
| 라운드 | 구매 25초 → 교전 90초. 한 라운드에 목숨 하나, 부활 없음 |
| 공격 팀 | 두 거점 중 한 곳에 **정화 씨앗**을 심고(4초) 싹이 틀 때까지(35초) 지키면 승리 |
| 수비 팀 | 시간이 끝날 때까지 심지 못하게 하거나, 심긴 씨앗을 뽑으면(6초) 승리 |
| 전멸 | 상대를 모두 쓰러뜨리면 승리. 단 씨앗이 심긴 뒤에는 수비가 뽑아야 한다 |
| 경기 시간 | 15~20분을 목표로 수치를 맞춘다 |

씨앗은 한 명이 들고 있고, 쓰러지면 떨어뜨린다. v0.1의 "씨앗 쟁탈전"을 이 모드로 흡수했다.

### 라운드 자금

- 매 라운드 자금을 받는다(승리 > 패배, 연패하면 패배 보상이 오른다). 처치와 씨앗 심기에 추가 보상.
- 구매 시간에 무기·보호구·도구를 산다. 살아남으면 장비가 다음 라운드로 이어지고, 쓰러지면 잃는다.
- 무기는 아레나 전용 목록이며 성능이 고정이다(월드의 개조는 적용되지 않는다).

### 사격과 이동 (아레나 규칙)

같은 플레이어 컨트롤러와 무기 코드를 **다른 규칙 묶음**으로 쓴다(`data/profiles.json`의 `arena`, `data/weapons_arena.json`).

| | 협동 (PvE) | 전술 아레나 (PvP) |
| --- | --- | --- |
| 이동 | 달리기, 슬라이딩 | 달리기·슬라이딩 없음. Shift는 발소리 없는 걷기 |
| 정지 사격 | 약간 퍼짐 | 첫 발이 거의 정확 |
| 이동 사격 | 조금 더 퍼짐 | 크게 퍼짐. 멈추고 쏴야 한다 |
| 공중 | 조작 가능 | 방향 전환 거의 불가, 사격 부정확 |
| 반동 | 가볍고 빨리 회복 | 정해진 패턴으로 크게. 연습으로 제어 |
| 처치 속도 | 적 체력이 높아 길다 | 소총 머리 한 발, 몸통 3~4발 |
| 체력 | 100, 자동 회복 | 100 + 구매한 보호구, 회복 없음 |

발소리와 총소리의 방향이 정보가 된다. 걷기는 소리가 없고 뛰면 들린다.

### 보조 무기와 투척류

캐릭터별 능력은 없다. 6장의 원칙 그대로, 전술 요소는 구매 시간에 사는 **보조 무기 1개와 투척류 2개**다. 전부 "시야와 위치"를 다루며 직접 피해는 거의 없다. 한 번 쓰면 사라지고, 살아남으면 남은 것이 다음 라운드로 이어진다.

| 종류 | 이름 | 효과 |
| --- | --- | --- |
| 투척 | 포자 연막 | 던진 자리에 15초간 시야를 막는 구름 |
| 투척 | 섬광 꽃가루 | 터질 때 바라본 사람의 화면을 잠깐 가린다 |
| 투척 | 탐지 씨앗 | 박힌 곳 주변의 적 위치를 잠깐 드러낸다 |
| 보조 무기 | 씨앗 발사기 | 통로를 막는 덩굴 벽이 몇 초 자란다. 쏘면 부서진다 |
| 보조 무기 | 권총 | 기본 지급 |

출시 구성은 권총, 연막, 섬광. 나머지는 확장이다.

### 맵

- 전용 소형 맵 1개로 시작한다: 거점 2곳, 주요 진입로 3개, 4v4 기준.
- 1v1·2v2는 같은 맵에서 거점 하나를 닫아 쓴다.

### 판정과 공정성

- 명중 판정은 협동과 같은 "사수 판정 + 호스트 검증"(D-005)으로 시작한다. 전용 서버가 없으므로 호스트가 지연 면에서 유리하다는 한계를 받아들이고, 경기 화면에 각자의 지연을 표시한다.
- 친구끼리의 이벤트 대전이며 순위전·매칭·부정행위 방지 체계는 만들지 않는다.

### 그 밖의 미니게임

페인트 배틀(즉시 부활 데스매치), 서바이벌, 장애물 레이스는 같은 "경기" 틀에 얹는 확장 후보로 남긴다. 페인트 배틀은 아레나 사격 연습용 준비 운동 모드로 가장 먼저 붙일 수 있다.
