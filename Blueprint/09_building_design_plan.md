# 09. 건축 디자인 및 사용성 보완 계획 (제안)

> **문서 상태: 설계 보완안 / 미확정 제안**
>
> 이 문서는 Edenfall Blueprint 01~08의 확정 사항을 바꾸지 않고, M2 건축 시스템의 조작 경험과 M3 이후 아트 확장 방향을 구체화한다. 기존 문서와 내용이 충돌하면 기존 확정 사항을 우선한다. 새로운 기능·키 배치·아트 요소는 별도 결정 전까지 구현 요구사항으로 간주하지 않는다.
>
> 기준: Godot 4.7.2, 스타일라이즈드 로우폴리, 연결형 수작업 오픈존, 1~8인 협동, 공장 소형→대형 자유 확장.

## 1. 목표와 사용자 경험

- 집·정원·공장을 **하나의 건축 시스템**에서 다룬다.
- 정확하게 맞춰야 하는 건물과 공장 설비는 격자로, 공간을 꾸미는 장식은 자유 배치로 다룬다.
- 작은 작업장 → 주택과 농장 → 다층 공장·물류 공간으로 자연스럽게 확장되도록 한다. 공장 규모를 강제하지 않는다(D-001).
- 초보자도 눈앞에서 배치 결과를 예측할 수 있고, 실수해도 손해 없이 수정할 수 있어야 한다.
- 파쿠르와 FPS가 공존하므로, 건축물의 실제 충돌·높이·이동 가능한 표면을 우선 검증한다.

## 3. 통합 건축 모드와 화면 흐름 (조작 제안)

건축 메뉴는 기존 분류에 맞춰 네 탭으로 구성한다.

1. **건물:** 바닥·벽·계단·지붕
2. **산업:** 채굴기·제련기·조립기·벨트·분배기·저장소·발전기·중계 기둥 등 기존 구조물
3. **자연:** 밭·화분(슬라이스), 확장 시 울타리·나무·연못 등
4. **인테리어:** 의자·탁자·등불·화분·울타리 등 슬라이스 장식 5종 범위

### 기본 이용 흐름

1. 플레이어가 건축 모드에서 구조물 종류를 선택한다.
2. 카메라가 바라보는 위치에 반투명 미리보기(고스트)를 표시한다.
3. 설치 가능 여부를 초록/빨강 색상과 짧은 텍스트로 알린다(예: 위치 중복, 지지 없음, 재료 부족, 권한 없음).
4. 필요한 경우 회전하거나 위치를 조정한다.
5. 설치 요청을 호스트에 보낸다. 호스트가 재검증·재료 차감·구조물 등록을 한 번의 승인 작업으로 처리한다.
6. 호스트의 결과를 전원에게 반영한다. 거절될 경우 사유를 표시하고 인벤토리는 바뀌지 않아야 한다.

### 입력키는 아직 확정하지 않음

- **Tab:** 건축 모드 열기/닫기 *후보*.
- **좌클릭:** 건축 모드일 때 설치 *후보*. 일반 모드의 사격과 입력 충돌을 막아야 한다.
- **R:** 건축 모드에서만 회전 *후보*. 현재 R은 재장전이므로 컨텍스트 분리가 필수다.
- **우클릭:** 선택 취소 *후보*. 현재 우클릭은 조준(ADS)이다.
- **Esc:** 취소 또는 모드 닫기 *후보*. 현재 일시정지/마우스 포커스와의 우선순위를 별도 검토한다.
- 현 샌드박스의 **B(저장소), N(기준 라인), X(철거)**는 개발용 입력이며, 새 모드가 완성되기 전에는 동작을 바꾸지 않는다.

키 설정과 조작 순서는 사용자 테스트 뒤 확정하며, 이 문서만으로 기존 입력 체계를 변경하지 않는다.

## 4. 집 건축과 인테리어

### 집 건축

- 먼저 바닥으로 공간을 확장하고, 벽과 지붕을 조합해 내부 공간을 만든다.
- 계단은 여러 층을 연결한다. 기존 4m 층 높이를 유지한다.
- 바닥·벽·계단·지붕은 공통 격자와 규격을 사용해 틈이나 겹침이 생기지 않도록 제작한다.
- 벽/지붕 설치 방향과 연결 위치가 명확하게 보이도록 미리보기와 스냅 표시를 검토한다.
- 파쿠르로 지붕·난간·제작 구조물 위를 이동할 수 있으므로 표면 충돌과 올라타기 가능 여부를 함께 확인한다.

### 꾸미기

- 의자·탁자·등불·화분 등은 자유 위치와 Y축 회전을 지원한다.
- 장식은 건축 격자 칸을 점유하지 않되 실제 충돌 검사는 한다.
- 실내·야외 배치 모두 가능하도록 아트와 배치 규칙을 일관되게 유지한다.
- 세밀한 위치 조정, 연결점 자석 스냅 등은 **사용성 개선 후보**이며 슬라이스 필수 기능을 늘리지 않는다.

### 확장 시 검토 (M3 이후 후보)

- 문·창문형 벽, 경사지붕, 모서리 지붕, 목재·석재·금속·유리 외형 변형.
- 이들은 **초기 M2 필수 기능이 아니다**. 이미 확정된 4종 건물 조각 및 5종 장식의 구현과 검증을 우선한다.
- 추가 에셋을 만들더라도 기존 1m 격자, 4m 모듈, 충돌 및 파쿠르 규칙에 맞춘다.

## 5. 공장 건축과 물류를 한 건축 모드에서

- 주택 옆 야외 작업대, 별채 공장, 다층 산업 시설 모두 같은 격자 기반으로 확장한다.
- 공장 설비마다 **차지하는 공간, 입력/출력 포트, 설치 방향, 필요한 자원**을 고스트에 표시하는 방안을 제안한다.
- 벨트는 기존 규칙대로 시작점과 끝점을 지정해 직선으로 설치하며, 높이 차이는 경사 구간으로 처리한다.
- 벨트의 아이템은 물리 객체가 아닌 시뮬레이션 슬롯 데이터를 시각화한다(D-008).
- 전력은 기존의 반경 기반 전력망을 유지한다. 이번 계획에서 전선 배치나 별도의 배전 미니게임을 추가하지 않는다.
- 설치 이후 기계 상태(가동, 재료 부족, 출력 막힘, 전력 부족)를 읽기 쉽게 표시한다.
- 여러 층에서 시설을 가동하더라도 현재 공장 시뮬레이션의 포트 연결·점유·고정 틱 규칙을 바꾸지 않는다.

## 6. 오류 방지와 편의 기능

### M2에서 기존 확정된 기능

- **미리보기:** 설치 성공/실패 및 사유 표시.
- **회전:** 격자 구조물 네 방향.
- **스포이트 복사:** 조준한 구조물의 종류와 회전을 손에 듦.
- **되돌리기:** 본인의 최근 설치/철거 20개. 이후 다른 변경과 충돌하면 실패.
- **철거:** 철거 가능한 구조물은 자원 100% 환급.
- **역할 검증:** 방문자 설치·철거는 클라이언트가 임의 요청해도 호스트에서 거절.

### 이후 확장으로 유지할 기능

- 영역 드래그 일괄 철거.
- 건축 청사진(구조물 배치 영역 저장·재설치).
- 다양한 외형/색상, 대량 건축 편의 기능.

기존 블루프린트의 M2 범위를 넘어서는 기능은 별도 우선순위 검토 전까지 추가하지 않는다.

## 7. 건축물 시각 디자인 원칙 (아트 방향 제안)

확정 아트 스타일인 **스타일라이즈드 로우폴리**를 유지한다.

- **주거:** 따뜻하고 부드러운 실루엣, 자연과 어울리는 형태.
- **공장:** 규격이 정확하고 동작·방향을 읽기 쉬운 실루엣, 절제된 발광 포인트.
- **공통:** 어느 쪽을 섞어도 이질적이지 않도록 비례, 조명 반응, 색상 톤을 통일한다.
- **인테리어:** 적은 수의 부품으로도 아늑하게 보이도록 명확한 형태와 배치 자유도에 집중한다.
- **월드:** 원래 정원과 메마른 골짜기 구성을 유지하고, 건축 가능한 안전 구역의 가시성과 여유 공간을 확보한다.
- **전투 시인성:** 적·엄폐물·사격 효과를 혼동하지 않도록 장식의 시각적 복잡도를 관리한다.

재질 팔레트, 상세 건물 외형, 날씨, 낮밤, 외주/구매 비율은 아직 미확정이며 이 문서에서 강제로 결정하지 않는다.

## 8. 협동·저장·성능 준수 사항

- 건축 요청은 호스트 권한 아래 검증하고, 멀티 클라이언트에는 확정된 구조물 변경 이벤트를 공유한다.
- 설치자 ID를 기록하되, 기존 월드 단위 역할 3종을 당장 바꾸지 않는다.
- 자원 차감과 구조물 설치는 중복 요청이나 통신 지연에도 어긋나지 않도록 일관성 있게 처리해야 한다.
- 철거 환급, 되돌리기, 재시작 후 구조물·설비·인벤토리 상태 보존을 함께 검증한다.
- 렌더링은 기존 MultiMesh/거리 기반 표시 최적화 계획을 따른다. **멀리 있는 공장을 시각적으로 단순화해도 생산 계산은 동일하게 유지**한다(D-010).
- 기준 사양 GTX 1660급, 6코어 CPU, 1080p, 60FPS 목표를 유지한다.
- 500개 설비, 2인 자동화 라인, 강제 종료 후 복구 등 M2의 기존 통과 기준을 변경하지 않는다.

## 9. 단계별 적용안 (기존 마일스톤 변경 없음)

| 단계 | 건축/디자인 작업 |
| --- | --- |
| M2 — 건축·공장 | 격자/자유 배치, 고스트, 회전, 벨트 드래그, 공장 표시, 인벤토리·제작, 권한, 저장, 되돌리기·복사, 밭/작물 |
| M3 — 버티컬 슬라이스 | 실제 정원·골짜기 맵에 건축을 자연스럽게 통합, 임시 에셋 정리, 복원 연출과 미술 품질 점검 |
| M4 — Steam·8인 | 추가 건축 기능보다 8인 네트워크·사용성·그래픽 설정 검증 |
| M5 — 콘텐츠·데모 | 문·창문·지붕 변형, 재질/색상, 청사진, 일괄 철거 등 범위에 맞춰 선별 확장 |

## 10. 개발 시작 전에 확인할 열린 항목

1. 건축 모드 전용 입력키 및 일반 FPS 입력과의 충돌 처리.
2. 지면 경사에서 기본 바닥 배치를 어떻게 안내할지(지형 변형 기능은 추가하지 않음).
3. 건축 미리보기와 재료/권한 부족 사유를 어느 정도 UI로 표시할지.
4. 구조물 조각의 연결점·충돌 형상이 파쿠르 동작과 일치하는지.
5. 기존 장식 5종을 어떤 외형으로 제작할지.
6. 500개 설비와 큰 다층 건축물에서 실제 프레임 성능이 유지되는지.

## 11. 문서 적용 원칙

- 이 문서는 **기존 Blueprint 01~08 문서의 변경 요청이 아니다**.
- 기존 확정 규칙은 그대로 적용하며, 본문에서 '제안', '후보', '확장'이라고 표시한 사항은 별도 확정 전까지 미정이다.
- 이번 단계에서 코드, 테스트, CI, 기존 에셋, 세이브 포맷, 다른 블루프린트 파일을 변경하지 않는다.
