## M3 재미 검증 실패 시 대비책

슬라이스가 재미 기준을 통과하지 못했을 때 원인별로 줄일 방향을 미리 정해 둔다.

| 증상 | 대응 |
| --- | --- |
| 전투는 재미있는데 공장이 숙제처럼 느껴진다 | 공장을 "작업장" 수준(수동 + 소규모 자동화)으로 줄이고 탐험·전투 비중을 올린다 |
| 공장은 재미있는데 전투가 방해로 느껴진다 | 전투를 선택형 콘텐츠로 내리고 Q-07을 앞당긴다 |
| 각각은 괜찮은데 이어지는 느낌이 없다 | 아이템 연결을 늘리기 전에 목표 제시(UI, 안내)를 먼저 고친다 |
| 혼자서는 지루하다 | 싱글 진행 속도(생산 배율, 적 수)를 조정한다 |
| 2인 동기화 문제가 재미를 가린다 | 콘텐츠 작업을 멈추고 M0~M2의 네트워크 부채를 갚는다 |
