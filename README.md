# Edenfall

Godot 4.x로 만드는 3D 협동 게임. **가꾸고(힐링) · 자동화하고(공장) · 싸워서(FPS) · 세계를 복원한다.**
1~4인 협동 PvE, Steam(Windows 우선) 출시 목표.

현재 단계: **설계 확정(Blueprint v0.2) → M0 착수 전**. 아직 게임 코드는 없다.
