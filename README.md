# Edenfall

Godot 4.7.2로 만드는 3D 협동 게임. **가꾸고(힐링) · 자동화하고(공장) · 싸워서(FPS) · 세계를 복원한다.**
1~8인 협동 PvE(싱글 플레이 가능), Steam(Windows 우선) 출시 목표.

현재 버전 **0.5.3** — M5(콘텐츠 확장) 진행 중: 설비 확장, 연구, 두 번째 구역 완료.

| 되어 있는 것 | 상태 |
| --- | --- |
| 설계 문서 (Blueprint v0.3) | 완료 |
| 공장 시뮬레이션 코어: 벨트, 채굴·제련·조립, 분배/합류, 저장, 발전·전력망, 저장/불러오기 | 단위 테스트 20개 통과 |
| 사격 감각 테스트용 사격장: 이동, 무기 3종, 수치 조정 패널, 협동/전술 아레나 규칙 전환(F2) | 첫 버전, 사람의 평가 필요 |

| 개발용 샌드박스, 파쿠르(올라타기, 매달리기, 벽 달리기, 벽 차기), 근접 공격 | 완료 |

| 설비 확장: 태양광·풍력·축전지, 고속 벨트, 관수기·자동 수확기, 층을 잇는 경사 벨트 | 단위 테스트 통과 |

## 빌드

Windows 빌드는 `v*` 태그를 푸시하거나 Actions에서 수동 실행할 때만 만들어진다.
자세한 것은 [Blueprint/08_dev_process.md](Blueprint/08_dev_process.md#테스트-빌드).

## 직접 실행

Godot 4.7.2(표준판)로 이 폴더를 열고 F5. 테스트는:

```bash
godot --headless --import
```

```bash
godot --headless -s tests/run_tests.gd
```
